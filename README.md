# Local_Module_Monitor
Монитор Локального модуля
автономный файл лежит в public/ и раздаётся вместе с приложением.
Где скачать в Git: прямо на дашборде, сразу под сводным статусом — яркая оранжевая панель «Автономный инструмент · один файл» (с пульсирующей подсветкой, её не пропустить):

    большая оранжевая кнопка «Скачать monitor-kkt34.html» — сохраняет файл на компьютер (с уведомлением-подтверждением);
    рядом ссылка «Открыть в браузере» — запускает инструмент в новой вкладке прямо отсюда;
    ниже показаны размер файла и число строк, плюс шаги 1 → 2 → 3: Скачайте → Откройте → Пользуйтесь.

Как запустить скачанный файл:

    Сохраните monitor-kkt34.html в любую папку (например, на рабочий стол кассира).
    Двойной щелчок по файлу — он откроется в любом браузере и сразу заработает. Ничего устанавливать не нужно: ни Node.js, ни сервера, ни интернета — весь HTML, CSS и JS внутри одного файла (как в исходном .hta-скрипте, только современнее).
    Ярлык на файл можно закрепить на панели задач — монитор будет запускаться одним кликом.

Что умеет автономный инструмент: весь функционал веб-версии — 12 служб с рестартами и «Рестартом всех», статус API :5995, инициализация токеном (с демо-токеном), авто-восстановление служб, журнал с фильтрами, сворачивание в трей, спарклайн пинга, инжекция сбоев. Настройки (интервал опроса, переключатели, принятый токен) сохраняются локально в браузере и восстанавливаются при следующем запуске.
